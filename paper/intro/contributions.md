# 1.3 Contributions

Framework novelty: using the transfer matrix as the tranining signal to create a model that actually predicts transfer performance for wildfire models.

Asymmetry-aware architecture: stepping away from standard feature-discrepancy and designing a model that addresses the inherent asymmetry present in domain transfer.

Externally-validated embedding space: using pyromes, lccs classes, and koppen climate zones as a way to validate that each of the respective branches of the encoder (fire, ground, atmo) correlates with real world, scientifically backed environmental regime delineations.

Bias terms as independent qualities: source and target biases are generated by the transfer model, and they correlate with the baseline quality for a domain's transferability on either the source or target end of the transfer.

Transfer is not model-agnostic: different models classes trained on the same sets of data view transferability differently, as seen by low correlation between each model class's transfer matrix.


~~
This work makes five primary contributions:

A supervised framework for wildfire transferability. We use an empirically constructed transfer matrix as the training signal for a model that predicts wildfire model transferability from the characteristics of the source and target regions.
An asymmetry-aware transferability model. The proposed architecture separates source and target effects, allowing it to represent directional transfer relationships that symmetric feature-discrepancy measures cannot capture.
An externally validated environmental embedding space. The encoder separates domain characteristics into fire, ground, and atmospheric branches. The resulting representations are validated against established ecological classifications, including pyromes, land cover classes, and Koppen climate zones.
Independent source and target quality representations. The model learns separate source and target bias terms that correspond to how well a domain transfers to other regions as a source and how well it receives transfers as a target.
Empirical evidence that transferability is model-dependent. Transfer matrices generated by different model classes show limited agreement when trained and evaluated on the same domains, demonstrating that measured transferability depends on the inductive bias of the underlying predictive model.
