## 1.2 Related work

There have been approaches that utilize a transferability matrix, basically a N x N table of N domains, where each (i,j) entry represents the accuracy of a model trained on domain i and applied to domain j. No work has been done to use the transfer matrix as training data for a model, they focus on clustering regions of the matrix and analyzing them. 

Generating a full transfer matrix also requires N models to be trained and N^2 evaluation loops. As will be further shown, transferability is not model-agnostic, meaning the inductive biases of model used to generate the matrix will be present in the transferability rankings it generates. This approach also inherentlydoes not generalize, since to add a new domain, an extra model will need to be trained and 2N+1 evaluation loops will need to be ran.

Taking a step back, one way to sidestep the 'model dependent' nature of a transfer matrix is through unsupervised domain adaptation. Existing feature discrepancy methods like mean maximum discrepancy or wasserstein distance are a proxy for transferability by measuring feature similarity between domains. This has been not only been disproven to be a strong measure of transferability, but it also assumes symmetric transfer due to feature distance being a symmetric measure.

Tools like Domain2Vec predict feature transferability specifically for image data. There has not been a generalized framework for predicting domain transferability using tabular data. This paper attempts to apply a generalizable framework to wildfires, though these same ideas can be reused for globally heterogenous environmental processes such as flodding and drought prediction.

A common way to study transfer between regions is to construct a transfer matrix. For N regions, the matrix contains N by N entries, where each entry represents the performance of a model trained in one region when applied to another. The resulting matrix provides a direct view of which regions transfer well to one another and can be used to identify clusters or patterns of similar regions. Similar matrix-based analyses have been used in wildfire and other environmental modeling studies.

However, the transfer matrix is generally treated as the result of the analysis rather than as data that can be used to predict transferability. To construct the full matrix, a separate model must be trained for each source region and evaluated on every target region. Adding a new region therefore requires training another model and running a new set of cross-region evaluations. The resulting transferability estimates also depend on the model used to generate the matrix, since different models can learn different relationships from the same source data.

One alternative is to avoid training region-specific models altogether and estimate transferability from how similar two regions are. Methods such as maximum mean discrepancy and Wasserstein distance measure differences between data distributions and have been used as proxies for how difficult transfer may be. These approaches remove the need to build a full transfer matrix, but they measure similarity rather than transfer performance itself. They also produce symmetric measures, so the difference between region A and region B is the same as the difference between region B and region A. This cannot represent cases where transfer works well in one direction but poorly in the other.

Other work has attempted to learn representations of domains that capture their relationships. Domain2Vec, for example, learns vector representations of visual domains and uses those representations to describe relationships between image datasets. More recent work such as GeoSPOT similarly uses distances between geographic domains to estimate cross-domain transfer difficulty. These approaches demonstrate that information about a domain can be compressed into a representation that is useful for reasoning about transfer, but they do not provide the same framework as the present problem: predicting wildfire model transferability from environmental characteristics of two regions using transfer performance as the supervised signal.

To our knowledge, prior wildfire transferability studies have used transfer matrices primarily to characterize and analyze cross-region model performance rather than to train a separate model that predicts previously unseen entries in the matrix. This paper instead treats measured transferability as a supervised learning target. The resulting model can estimate transfer between regions from their environmental characteristics without first training and testing a wildfire model on every pair of regions.

The framework is designed for wildfire prediction, but the underlying problem is broader. Many environmental processes are spatially heterogeneous and have uneven data coverage, creating the same question of whether knowledge learned in one region can be transferred to another. A method for predicting transferability from regional characteristics could therefore also be applied to processes such as flooding or drought, where direct evaluation across every pair of regions would be similarly expensive.
