## Transfer matrix construction

After defining each of the 34 domains, fire event samples were collected for each of the domains. cell is defined as a (lat,lon,time) point in the datacube, and a fire event is a cell where the burned area is greater than 0. 
After getting every fire event, tagged by domain id, i had to deal with missing values in dataset:
Knn imputation for swvl variables using precipitation, humidity, and temperature as features since they physically determine soil state
Temporal imputation ndvi (drop long gaps) since vegetation greenness does not rapidly change over time
Drop missing rows for pop den, fwi, ssrd since the missing values collectively made up ~1% of the dataset

The general idea is to train 34 models, one for each domain, based on that domain's wildfire data (fire events). the target variable is burned area (it was log-scaled for more stable training) and features were as follows: fwi_mean	 lccs_class_1	lccs_class_2	lccs_class_3	lccs_class_4	lccs_class_6	lccs_class_7	ndvi     pop_dens	rel_hum	skt	ssr	ssrd	swvl1	swvl2	swvl3	swvl4	t2m_max	t2m_mean	t2m_min	tp	vpd	ws10

Using this, I created per-domain train-test X-y splits and scaler. Essentially, each domain would have it's own training data (features + target), its own testing data (features + target), and a standard scaler fit to the training features.

The transfer matrix is made up of 34 domain-based models that are tested on every other domain. for each domain, a model was trained using it's own scaled training data. when applied to other domains, it would access the test data for that domain, and the raw feature values would pass through the source domain's feature scaler (not the target-side scaler) in order to project the data to a space that the source-side model is familiar with. basically, for domain pair (i,j), where i is source domain and j is target domain: train model_i using i_train_x raw values, scaled by the scaler for domain i; then test model_i on j_test_x raw values, scaler by the scaler for domain i; then report performance compared to j_test_y. this also applies when i=j. ensuring there is a heldout set of data per domain ensures there is no leakage of data. data for test set is determined by random selection rather than a temporal split as to not confound spatial generalization with temporal generalization when making the matrix (we test how a model trained on domain i's 2011-2021 data performs on domain j's 2011-2021 data, and misaligning the temporal ranges mean that this comparion would account for both spatial and temporal drift).

The word 'model' is used loosely, and that is because we empirically show how the type of model used as the base model to generate the transfer matrix has a large effect on the transfer matrix itself. a transfer matrix using xgboost, random forest, and neural network were each created. there was no hyperparameter tuning for each domain's base model in the effort to reduce compute, as this would result in 34x34x3 rounds of hyperparameter tuning. instead for each model type, the same architecture was used across all domains in order to keep consistency. the original assumption was that transferability would be model-agnostic, meaning there would have been strong correlation between these tree transfer matrices. there was not, however, with the highest correlation being a modest value between xgboost and random forest, which makes sense since they are both tree-based boosting methods. 

this shows transferability depends on the model used, meaning each model type has its own 'view' of transferability shaped through its own inductive bias. it would not make sense to simply take an average of the three matrices to create the ground truth transfer matrix, as this smooths over the views of the models and loses out on actual signal. instead, i ran a seed stability test in which i geenrated a new rf, xgb, and nn transfer matrix but with a different random seed to train the base models. random forest had high seed stability, meaning it had a consistent 'view' of transferability. the xgb and nn matrices had low seed stability as matrices with the same base model type had low correlation between each other, indicating that their view of transferability heavily depended on random initialization. to generate the final ground thruth matrix, i took the average of the two seeds of the random forest transfer matrix. it's important to note that there logically cannot be a ground truth transfer matrix that is model-agnostic, as there cannot be a 'model-agnostic predictor', or a model that contains no inductive bias.

I also needed to choose a metric to create the transfer matrix, the requirements were as follows: must be normalized/scaled (abolute metrics are not comparable), must be bounded/relative (same reasoning as above), must be variance-indifferent (each domain has different fire distributions). This rules out MAE and MSE since those are absolute. this also rules out R^2 because variance is baked into its formula. It also heavily penalizes very incorrect predictions (outliers) due to squared error being baked into its formula. when making the transfer matrix for xgboost with R^2 as the performance metric, R^2 values for in-domain performance (i=j) were very low (around 0.1) and out of domain performance was around -0.05. The difference between out of domain and in domain performance was so little, and the performance using R^2 in general was low. The encoder model, if trained on an R^2 matrix, would only learn noisy performance values. this is why I switched to spearman correlation. It not only fits the criteria above, but it also showed a strong difference between in-domain performance (around 0.4) and out of domain performance (around 0.1), meaning an encoder model would have a better time differentiating between strong and weak transferability.

After defining the 34 wildfire domains, fire-event samples were extracted from each domain to construct an empirical transfer matrix. A cell was defined as a single latitude, longitude, and time point in the SEASFire Cube, and a fire event was defined as a cell with burned area greater than zero. Each fire event was assigned to its corresponding domain.

Missing values were handled before model training. SWVL1-SWVL4 values were imputed using k-nearest-neighbor imputation with precipitation, relative humidity, and temperature as predictors, since these variables are directly related to soil moisture conditions. Missing NDVI values were imputed temporally because vegetation greenness generally changes gradually over time, while prolonged missing intervals were discarded. Rows containing missing population density, FWI, or SSRD values were removed because these missing values collectively affected approximately 1% of the dataset.

A separate wildfire prediction model was then trained for each domain using only that domain's fire-event data. The prediction target was burned area after log transformation, which reduced the effect of the highly skewed burned-area distribution and provided more stable model training. The input features were FWI_mean, the available LCCS land-cover classes, NDVI, population density, relative humidity, skin temperature, surface solar radiation, surface solar radiation downwards, SWVL1-SWVL4, T2m_max, T2m_mean, T2m_min, precipitation, VPD, and wind speed. For each domain, the data were divided into training and testing subsets, and a standard scaler was fit using only the training features.

The transfer matrix was constructed by evaluating each domain-specific model on the held-out test data of every domain. For a source domain (i) and target domain (j), model (i) was trained using the training data from domain (i), with features standardized using the scaler fit to domain (i). The raw test features from domain (j) were then transformed using the same source-domain scaler before being passed to model (i), and predictions were compared with the held-out target values from domain (j). The same procedure was used when (i=j), producing the diagonal entries of the matrix. Using a held-out test set for every domain prevents the target observations used to evaluate transfer from entering the corresponding source model's training data.

Test observations were selected randomly rather than through a temporal split. This keeps the temporal range represented in the source and target domains aligned, so that the resulting transfer matrix primarily measures spatial transfer rather than conflating spatial transfer with temporal drift. In effect, the matrix asks how a model trained on fire events from one domain transfers to another domain over the same observation period.

The transfer metric was selected based on three requirements. First, it needed to be normalized so that transferability could be compared across domains with different burned-area distributions. Second, it needed to express relative predictive agreement rather than absolute error. Third, it needed to be insensitive to differences in target variance across domains. These requirements rule out MAE and MSE because their magnitudes depend directly on the scale of the target variable. R^2 was also unsuitable because its normalization by target variance makes comparisons sensitive to differences in variance among domains, and its squared-error formulation gives substantial weight to large prediction errors.

This distinction was apparent empirically. When an XGBoost transfer matrix was constructed using R^2, in-domain performance was approximately 0.1 and out-of-domain performance was approximately -0.05. The small separation between these values would provide a weak signal for distinguishing strong from weak transfer relationships. Spearman correlation provided a substantially clearer separation, with in-domain performance around 0.4 and out-of-domain performance around 0.1. Spearman correlation therefore satisfied the desired normalization and relative-comparison properties while providing a stronger empirical signal for transferability prediction. It was used as the transfer metric for the final matrix.

The choice of base model also affects the transfer matrix itself. To test whether the measured transferability was independent of the underlying wildfire prediction model, separate transfer matrices were constructed using random forest, XGBoost, and neural network base models. Hyperparameter tuning was not performed independently for each domain because doing so would require a separate tuning procedure for each of the 34 domains and three model types. Instead, a fixed configuration was used for each model type across all domains, ensuring that differences between transfer matrices reflected differences in model type rather than independently optimized configurations.

The three transfer matrices showed that transferability is not model-agnostic. The correlations between matrices were limited, with the strongest agreement occurring between random forest and XGBoost, which share tree-based model structure. The disagreement indicates that each model type provides a different view of transferability, shaped by its own inductive bias. Averaging the three matrices would therefore combine different model-specific relationships rather than recover a model-independent ground truth.

A seed-stability analysis was used to determine which base model provided a sufficiently consistent transfer signal for the final matrix. A second transfer matrix was generated for each model type using a different random seed. Random forest showed high agreement between its two matrices, indicating that its measured transfer relationships were stable across random initialization. XGBoost and the neural network showed substantially lower agreement between seeds, indicating that their transfer matrices were more sensitive to model initialization. The final empirical transfer matrix was therefore defined as the element-wise average of the two random forest matrices.

This construction does not produce a model-agnostic ground truth in the strict sense. Because every predictive model has an inductive bias, no predictor can provide a completely model-independent measure of transferability. The final matrix should therefore be interpreted as a stable empirical characterization of transferability under the random forest modeling framework.
