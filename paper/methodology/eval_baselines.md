## 2.7 and 2.8 - Baselines and Evaluation

In order to validate the model’s performance against current methods, I generated the full 34x34 transfer matrix using the transferability model as well as with other baseline methods. These matrices were compared against the ground truth random forest transfer matrix to see how each method predicts cross-domain model transferability.

The two feature discrepancy baselines used were maximum mean discrepancy and wasserstein distance, which calculate the difference between two distributions in different ways, but are commonly used in unsupervised domain adaptation as a proxy for domain differences. For an (i,j) cell in the transfer matrix, we take the mmd/wasserstein distance between the domains and report the negated output as the transferability. 
Raw distance between domain descriptors is used s a baseline, since if pure euclidean distance between the transferability model inputs can match the performance of the actual transferability model, it means there was no need for a model to transform and re-represent the descriptors. For an (i,j) cell in the transfer matrix, we take the domain descriptors for the source and target domains and compute their euclidean distance, which is then negated. This method is symmetric, just like with mmd and wasserstein, meaning an (i,j) cell will have the same value as (j,i).
the next baselines set up the cieling and floor for predictive performance on the transfer matrix. i trained an xgboost and linear regression model on the transfer matrix, where the input was (desc_i, desc_j, desc_i-desc_j), including a difference vector between descriptors to encode directionality and domain differences, and the output is the transferability score. like with the transferability model, 30x30 matrix is the training set, while the rest is for testing. xgboost sets the cieling for predictive accuracy because of it's ability to beat neural networks on smaller tabular datasets. linear regression sets the floor because of its simicity, with it only having 33*3+1 parameters.

Kendall tau is used as the primary evaluation metric for comparing transfer matrices. This is because kendall tau is indifferent to the variance and magnitude of the variables being compared, and it only tests for a monotonic/rank-based difference. Since these baselines will vary in their variance and magnitude (ex: feature discrepancy baseline values are negated to create the final matrix to show that greater discrepancy=worse transfer=more negative value) and we only care about rank differences between pairs (to show that domain B transfers better to domain A than domain C transfers to domain A, essentially being able to rank which domains are the best sources/targets for other domains and disregarding actual transferability magnitude since mmd/wasserstein/descriptor distance baselines all have negative values), kendall tau is the best metric for this case. It is also interpretable, with tau values being associated with percent of concordant pairs (ex: tau-b of 0.60 means 80% of non-tied pairs are concordant). Tau-b is used since it works best for square matrices.

The transferability model was evaluated against several baselines to determine whether learned domain representations provide information about transferability beyond direct measures of domain difference. For each method, a complete 34 x 34 source-target transfer matrix was generated and compared with the empirical random forest transfer matrix defined in Section 2.3.

Three unsupervised baselines quantify domain difference without learning a transferability-specific representation. Maximum mean discrepancy (MMD) and Wasserstein distance measure differences between the distributions of the two domains and are commonly used as measures of domain discrepancy in unsupervised domain adaptation. For each source-target pair, the corresponding MMD or Wasserstein distance was calculated and negated to produce a transferability score, such that larger values indicate greater similarity and therefore greater expected transferability. Raw Euclidean distance between the 33-dimensional domain descriptor vectors was included as a simpler baseline. For each pair, the descriptor distance was calculated and negated. Unlike the transferability model, none of these baselines learns a transformation of the descriptors. All three discrepancy-based baselines are symmetric, so the predicted transferability for (i -> j) is identical to that for (j -> i).

Two supervised baselines were used to establish reference points for predictive performance. XGBoost was trained directly on the empirical transfer matrix using the concatenation of the source descriptor vector, target descriptor vector, and their element-wise difference as input, with the transferability score as the output. The difference vector provides explicit information about directional differences between the source and target descriptors. The same 30 x 30 training matrix and held-out source-target pairs used for the transferability model were used for evaluation. XGBoost provides a high-capacity reference for tabular data, while linear regression provides a low-complexity reference using the same input representation. These models therefore provide empirical upper and lower reference points for how accurately the transfer matrix can be predicted from the domain descriptors.

Kendall tau-b was used as the primary metric for comparing predicted transfer matrices with the empirical transfer matrix. The objective of the transferability framework is primarily to rank source-target pairs rather than reproduce the exact numerical magnitude of the empirical transfer scores. This is important because the baseline methods produce scores on fundamentally different scales. For example, MMD, Wasserstein distance, and descriptor distance are converted to transferability by negation, whereas the empirical transfer matrix is expressed as Spearman correlation. Kendall tau-b evaluates whether the relative ordering between pairs is preserved without requiring the compared matrices to have the same scale or variance.

Tau-b was selected specifically because it accounts for tied rankings, which can occur in pairwise transfer matrices. A positive tau-b indicates that pairs receiving higher transferability scores from the evaluated method also tend to have higher empirical transferability, while a value near zero indicates little rank agreement. This evaluation therefore directly measures the ability of each method to identify which source-target transfers are relatively stronger or weaker, independent of the absolute magnitude of the predicted scores.
