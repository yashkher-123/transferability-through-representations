## Limitations

this project assumes that when a model is transferred to another region, it will directly be used for inference. in reality, it is entirely possible for a source model to be fine-tuned on the scarce data of the target domain in order to become more acclimated to the fire patterns of the target domain. my transfer matrix assumes direct transfer, ie take a model trained on domain i and test it on domain j without any fine tuning. my methods are still valid if we can show that direct transfer is a strong proxy for transfer after fine tuning: if a source model has strong direct transfer to a target domain, then it would also have strong fine-tuned transfer to the target domain.

the transfer model is trained on the seed-averaged random forest transfer matrix. the model technically predicts the transferability of a random forest model from domain i onto domain j. there is effectively little workaround for this issue, since the rf and xgb and nn transfer matrices disagreed with each other, and xgb/nn matrices disagreed with their own model class under seed stability tests. rf was chosen for seed stability, meaning it has a clear 'view' of transferability even under random changes in seed which would affect bagging procedures. there mathematically no way to make a ground truth transfer matrix that does not carry at least some inductive bias from the predictive model. there cannot be a predictive tool whose transfer matrix agrees with all of: rf, nn, xgb (since these models don't even agree with each other, they cant have simultaneous agreement with another model by transitive property). by definition, there cannot be a 'model-agnostic predictor', any model will carry some inductive bias which will alter its view of transferability.

The transfer matrix assumes direct transfer: a model trained on a source domain is applied to a target domain without any additional training. In practice, a source model could instead be fine-tuned using the limited wildfire data available in the target domain. The present framework therefore measures direct transferability rather than transferability after adaptation. Its conclusions would extend to the fine-tuning setting only if direct transfer is a useful proxy for the eventual performance of a fine-tuned model. Specifically, a source-target pair with strong direct transfer would need to also tend to produce strong performance after fine-tuning. Establishing that relationship is outside the scope of the present study.

The second limitation is more fundamental: the empirical transfer matrix is inherently dependent on the predictive model used to construct it. The final transferability model is trained on the seed-averaged random forest transfer matrix and therefore predicts transferability under the random forest inductive bias. This dependence could not be removed by simply selecting a different base model. Random forest, XGBoost, and neural network transfer matrices showed limited agreement with one another, while seed-stability analysis showed that XGBoost and the neural network also produced substantially different transfer matrices under different random seeds. Random forest was selected because its transfer relationships were comparatively stable across seeds, providing a consistent empirical view of transferability.

There is no model-independent ground truth transfer matrix that can simultaneously represent the transfer relationships of fundamentally different predictive models. Suppose a hypothetical transferability predictor exactly reproduced both the random forest and XGBoost transfer matrices. By transitivity, the random forest and XGBoost matrices would then have to agree with each other, contrary to the observed results. The same argument applies to the other model classes. More generally, every predictive model imposes an inductive bias, and that bias affects how its learned function generalizes between domains. Consequently, "model-agnostic transferability" cannot be defined as a single empirical quantity independent of the predictive model used to measure it.

The appropriate interpretation of the present framework is therefore not that it discovers a universal transferability relation between wildfire domains. It learns a stable representation of transferability for a specified predictive model class, in this case random forest. Extending the framework to another model class would require constructing and predicting that model's transfer matrix separately.
